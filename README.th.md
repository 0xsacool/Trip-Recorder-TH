# EV TripLog

Fork จาก [3freet/Trip-Recorder-NG](https://github.com/3freet/Trip-Recorder-NG) ภายใต้ GPL-3.0 สำหรับ BYD Atto 3 (BEV)

- ภาษาไทยเป็นค่าเริ่มต้น เปลี่ยนภาษาได้ใน Setting
- THB; ค่าไฟตัวอย่าง 4.50 บาท/kWh แก้ไขได้ตามค่าไฟจริง
- หน้าสถิติเน้นรถไฟฟ้าล้วน ไม่แสดงตัวชี้วัดน้ำมัน/ไฮบริด
- ความจุแบตเตอรี่เริ่มต้น 60 kWh แก้ไขได้ในการตั้งค่า; ใช้ประมาณพลังงานชาร์จเมื่อไม่มีค่าจริงหรือค่าที่เรียนรู้จากทริป และมีป้ายประมาณการ
- การอัปเดตตรวจสอบจาก Fork นี้ผ่าน GitHub Releases ไม่มีการอัปโหลดประวัติทริป
- ช่องทาง Beta ใช้ทดสอบ (`dev-N`); Stable ใช้รุ่นที่ผ่านการทดสอบ (`stable-N`)
- ก่อนเปลี่ยนจาก Build #1 ให้สำรองข้อมูลจากเมนูการตั้งค่า เพราะลายเซ็นชั่วคราวไม่สามารถติดตั้งทับ APK ที่ใช้ลายเซ็นถาวรได้
- Release ใช้คีย์ถาวรเท่านั้นผ่าน GitHub Actions Secrets (`SIGNING_KEYSTORE_BASE64` และ `SIGNING_KEYSTORE_PASSWORD`) ห้ามเก็บคีย์หรือรหัสผ่านใน repository

**สถานะ:** v1.0.0 Beta; ยังไม่ได้ทดสอบบนรถ Atto 3 จริง ฟังก์ชันข้อมูลรถขึ้นอยู่กับ DiLink และสิทธิ์ของระบบ เริ่มใช้ GPS-only ก่อน ไม่ควรเปิดเครื่องมือควบคุมรถ/กล้องจุดบอดจนกว่าจะทดสอบความเข้ากันได้

ใช้ package เดิม org.triprecorderng เพื่อความเข้ากันได้กับโครงสร้างเดิม แต่ APK ต่างลายเซ็นอาจติดตั้งทับต้นฉบับไม่ได้ หากติดตั้งต้นฉบับอยู่ ให้สำรองและส่งออกข้อมูลก่อนพิจารณาถอนการติดตั้ง

หลังติดตั้ง ให้ปิดสวิตช์ EV TripLog ใน Disable background Apps ของ BYD และรีสตาร์ตหน้าจอหนึ่งครั้ง

โปรเจกต์ไม่เป็นทางการ ดูคำเตือนและวิธี Build ที่ [README ต้นฉบับ](README.md)
